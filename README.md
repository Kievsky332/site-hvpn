## Описание проекта

Этот проект представляет собой  набор связанных страниц. Основная цель разработки заключалась в практике чистой верстки, работе с типографикой и создании визуально привлекательного интерфейса без использования тяжелых JavaScript-фреймворков.
>[!NOTE]
>  print("Мы осуждаем ВПН").

---

## Стек технологий

- **HTML5** — семантическая разметка лендинга
- **CSS3** — кастомная стилизация, работа с макетами и адаптивность

## Запуск локально


1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Kievsky332/site-hvpn.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd site-hvpn
   ```
3. Откройте файл index.html двойным кликом в любом современном браузере.
